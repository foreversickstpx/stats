Реализация методов описательной и индуктивной статистики для анализа выборки данных: от построения вариационного ряда до проверки статистических гипотез и расчёта доверительных интервалов.

## Задача

Проект по математической статистике. Цель — реализовать полный цикл первичного статистического анализа выборки: от порядковых статистик и характеристик распределения до проверки гипотез о законе распределения и построения доверительных интервалов для параметров генеральной совокупности.

## Реализованные методы

1. **Описательные статистики выборки** — таблица частот (Xi, Ni, Wi), выборочное среднее, дисперсия, среднее квадратическое отклонение, исправленная дисперсия и СКО
2. **Эмпирическая функция распределения** — построение по выборке
3. **Доверительные интервалы для математического ожидания**:
   - при известном σ (доверительные вероятности 0.9 и 0.95)
   - при неизвестном σ, через распределение Стьюдента (0.9 и 0.95)
4. **Доверительные интервалы для дисперсии** (через χ²), при известном и при неизвестном математическом ожидании, доверительные вероятности 0.9 и 0.95
5. **Проверка гипотезы о нормальном распределении** — критерий согласия Пирсона (χ²) и критерий Колмогорова
6. **Оценка параметров равномерного распределения тремя методами** — критерий Пирсона (метод моментов с группировкой/склейкой интервалов), метод максимального правдоподобия (ММП), несмещённая оценка с минимальной дисперсией
7. **Проверка гипотезы о равномерном распределении** для каждой из трёх оценок — критерий Пирсона (χ²) и критерий Колмогорова
8. **Сравнительная таблица** оценок параметров (a, b, 1/(b-a), χ²) по всем трём методам
9. **Расчёт степеней свободы и принятие/отклонение гипотез** на уровне значимости 0.05

## Особенность реализации

Расчёт описательных статистик, построение вариационного и интервального рядов, а также промежуточные вычисления для критериев согласия реализованы вручную. Табличные значения критических точек распределений (χ², статистика Колмогорова) берутся из `scipy.stats` — переизобретать таблицы статистических распределений нецелесообразно, поэтому для них используются готовые функции библиотеки.

## Стек

Python, NumPy, SciPy, statistics, PrettyTable (вывод таблиц в отчёт)

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Скрипт запросит имя выходного файла и выборку, после чего сформирует текстовый отчёт со всеми расчётами.
